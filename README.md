I am a Data Scientist and AI-focused software builder working across machine learning, big data, backend engineering, and LLM-powered applications. I like building systems that are not only smart in notebooks, but also reliable, observable, and useful in production.

- Currently building: **AI-powered operational intelligence platforms**
- Currently learning: **advanced ML systems, LLM fine-tuning, retrieval, and evaluation**
- Collaboration interests: **open-source AI, NLP, RAG, analytics, and data engineering**
- Ask me about: **PyTorch, FastAPI, LangChain, Airflow, dbt, Spring Boot, ML pipelines**
